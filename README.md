# G3 Architects

🔗 **Live Demo:** [https://newbie-saimur.github.io/g3-architects/](https://newbie-saimur.github.io/g3-architects/)

A modern, responsive website for G3 Architects - a visionary architectural firm specializing in innovative designs, sustainable solutions, and premium quality construction projects.

## 🏗️ About

G3 Architects is a team of visionary designers shaping the future of architecture. This website showcases their portfolio, services, and achievements, featuring a clean and professional design that reflects their architectural expertise.

## ✨ Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations and intuitive navigation
- **Portfolio Showcase**: Beautiful image gallery displaying team and project highlights
- **Service Highlights**: Detailed sections showcasing key features and services
- **Company Statistics**: Interactive facts and figures section displaying achievements
- **Sponsor Section**: Showcase of trusted partners and sponsors

## 🎯 Key Sections

- **Navigation Bar**: Easy-to-use menu with Home, About, Contact Us, and Login links
- **Hero Banner**: Compelling introduction with call-to-action
- **Features Overview**: Quick showcase of main architectural services
- **Detailed Features**: In-depth look at innovative designs, sustainable solutions, smart planning, and premium quality
- **Company Facts**: Statistics including 54 awards, 1458 completed projects, 590 clients, and 22578 emails sent
- **Sponsors**: Display of partner companies including Spotify, Amazon, Google, Telerama, and Figma

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better accessibility and SEO
- **CSS3**: Advanced styling with custom properties (CSS variables)
- **Google Fonts**: Work Sans font family for modern typography
- **Responsive Design**: Mobile-first approach with flexible layouts
- **CSS Grid & Flexbox**: Modern layout techniques for optimal positioning

## 🎨 Design Highlights

- **Color Scheme**: Professional orange (#FF900E) accent color with dark (#131313) and gray tones
- **Typography**: Work Sans font family for clean, readable text
- **Layout**: Strategic use of whitespace and organized content sections
- **Images**: High-quality architectural and team photography
- **Icons**: Custom icons for facts and statistics section

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/newbie-saimur/g3-architects.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd g3-architects
   ```

3. **Open the project**
   - Open `index.html` in your preferred web browser
   - Or use a local development server like Live Server in VS Code
